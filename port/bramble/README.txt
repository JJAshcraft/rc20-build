BRAMBLE - a wavetable synth for the R36S

PLAY MODE (SELECT switches between PLAY and EDIT)
  D-pad left/up/right/down   scale notes 1-4
  Y / X / A / B              scale notes 5-8
  L1 / R1                    octave down / up
  L2                         hold notes on/off
  R2                         arpeggiator on/off
  L3 / R3 (stick clicks)     previous / next sound
  Left stick                 left/right: wavetable position, up: vibrato
  Right stick                left/right: pitch bend, up/down: filter cutoff

EDIT MODE
  L1 / R1                    previous / next page
  D-pad up/down              choose a setting
  D-pad left/right           change it (hold B for big steps)
  Left stick left/right      sweep the setting smoothly
  A / X                      hear a note / a chord
  Y                          reset the setting to its default

ANYWHERE
  START                      sounds (presets): A load, X twice to save
  START + SELECT             quit (your last settings are kept)

Files in this folder:
  bramble_presets.txt   your saved sounds (plain text, safe to edit or share)
  bramble_state.txt     the settings Bramble reopens with
  bramble.cfg           button fixes and audio buffer size
  log.txt               messages from the last run
